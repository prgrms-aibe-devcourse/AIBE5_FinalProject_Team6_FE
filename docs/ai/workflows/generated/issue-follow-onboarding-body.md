## 📝 작업 내용

아티스트/크리에이터 팔로우/언팔로우 액션 시 UI 반응 및 팔로워 수가 즉각 반영되도록 개선하고, 팔로우 성공 시 프리미엄 감성의 웰컴 온보딩 모달창을 노출하여 사용자 경험을 향상시킵니다.

- **팔로우/언팔로우 즉시 반영**: 아티스트 상세 보드 헤더 및 아티스트 목록 그리드에서 팔로우 상태 토글 시 팔로워 수가 로컬 상태로 즉시 증감되도록 반영
- **팔로우 성공 온보딩 모달**:
  - 팔로우 처리 성공 시 웰컴 팝업 노출 ("[아티스트명]님을 팔로우하셨어요! 지금 당장 만나러 가볼까요?")
  - 흐린 유리 질감(Glassmorphism) 및 세련된 그라데이션, 마이크로 인터랙션을 반영한 프리미엄 UI 디자인
  - '나중에 하기' (모달 닫기) 및 '지금 가기' (해당 아티스트 피드 탭으로 즉시 이동) 액션 제공
- **안정성 확보**: API 통신 실패 시 상태 롤백 및 토스트 알림 노출로 사용자 피드백 제공
