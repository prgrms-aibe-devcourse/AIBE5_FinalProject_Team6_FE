## 📝 작업 내용

- ARTIST 피드 카드 작성자 표시: 그룹명 → 멤버명 (memberId→name 맵 빌드)
- Admin Content Monitoring: Posts/Comments 탭 + 상태 뱃지(SPAM/REPORTED/APPROVED) + 샘플 데이터 라벨
- Admin Orders: 상태 뱃지 컬러 코딩 + 샘플 데이터 라벨

## 🧪 기술적 의사결정

피드 로드 `useEffect`에서 `getArtistMembersList`를 `Promise.all`로 병렬 호출해 `memberMap` state를 구성했다. 별도 `useEffect`를 추가하지 않고 피드 로드와 결합해 요청 수를 최소화했다. `ContentMonitoringPanel`은 컴포넌트로 분리해 AdminApp 함수 본문을 가볍게 유지했다.
