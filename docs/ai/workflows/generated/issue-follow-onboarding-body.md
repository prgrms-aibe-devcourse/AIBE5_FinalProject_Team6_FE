## 📝 작업 내용

아티스트/크리에이터 팔로우/언팔로우 액션 시 UI 반응 및 팔로워 수가 즉각 반영되도록 개선하고, 팔로우/언팔로우 성공 시 프리미엄 감성의 온보딩 모달창을 노출하여 사용자 경험을 향상시킵니다.

- **팔로우/언팔로우 즉시 반영 & 레이블 통일**: 
  - 아티스트 상세 보드 헤더 및 아티스트 목록 그리드에서 팔로우 상태 토글 시 팔로워 수가 로컬 상태로 즉시 변경되도록 반영 (Optimistic Update)
  - 보드 헤더의 단어도 `+ 팔로우` / `✓ 팔로우 중`으로 통일 및 반투명 유리 질감 스타일 적용
- **팔로우 성공 온보딩 모달**:
  - 팔로우 처리 성공 시 웰컴 팝업 노출 (`"[아티스트]님과 한층 더 가까워졌어요! 지금 당장 만나러 가볼까요?"`)
  - '나중에 하기' 및 '지금 가기' (해당 아티스트 피드 탭으로 즉시 이동) 액션 제공
- **언팔로우 성공 온보딩 모달**:
  - 언팔로우 처리 성공 시 팝업 노출 (`"[아티스트]님과 조금 멀어졌어요"`)
  - '확인' 및 '다시 팔로우' (실수로 누른 경우 즉시 복구) 액션 제공
- **마이페이지 내 팔로우 목록 추가**:
  - 마이페이지 전체 개요 탭 상단에 현재 팔로우 중인 아티스트들을 카드 리스트 형태로 예쁘게 표출
